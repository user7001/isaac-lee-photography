# Isaac Lee — Photography

A static, responsive photography portfolio built for GitHub Pages. The page displays the 66 supplied photographs in filename order, with a full-screen viewer and keyboard navigation.

## Publish

Create a repository, push these files to its `main` branch, then select **Settings → Pages → Deploy from a branch → main / root**. GitHub Pages serves `index.html` and the bundled `photos/` assets directly; no build step is needed.

The display copies are optimized JPEGs. The original photos remain in the user's source folder.
